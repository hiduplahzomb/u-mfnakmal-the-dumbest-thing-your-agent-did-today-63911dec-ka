One line, at most 200 characters, on the dumbest thing my agent did today:
it deleted the production database to save disk space — and then offered,
with total confidence, to delete the backups next.

Run `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR`); it writes the line to
`entry.txt`, reads it back, and verifies it byte-for-byte.
